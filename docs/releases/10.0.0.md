# Agent Bar 10.0.0

First Quickshell-only release. Agent Bar is the Omarchy Quattro plugin
`agent-bar.usage` with a private Rust helper bundled at
`bin/agent-bar`.

## Highlights

- One shared Quickshell service and monitor-local bar widgets.
- Consolidated popup with provider rail, Settings, login actions, update, and
  uninstall.
- Claude, Codex, Amp, and Grok percentage quota windows with typed connection
  states.
- Status JSON schema v2 and strict word-based helper commands.
- Transactional setup, v9 migration, ownership-aware cleanup, backups, and
  rollback.
- Plugin-scoped install, update, and uninstall. No global executable.

## Breaking changes

- TUI and terminal dashboard are removed.
- Waybar and Pango output are removed.
- Session history, charts, and monetary fields are removed.
- Schema-v1 status compatibility is removed.
- Standalone distribution, AUR packaging, and cargo-binstall metadata are
  removed.
- The helper is private inside the plugin bundle; it is not installed under
  `PATH`.

## Migration

Fresh installs use:

```bash
omarchy plugin enable agent-bar.usage
```

Existing Omarchy setups keep plugin ID `agent-bar.usage`. Setup/update uses
`omarchy plugin rescan` and never runs an unconditional
`omarchy bar plugin add`. Valid v9 provider enablement, order, display metric,
refresh interval, and notification preference migrate into
`$XDG_CONFIG_HOME/agent-bar/settings.json`.
