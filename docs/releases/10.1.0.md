# Agent Bar 10.1.0

Claude usage monitoring restored and the popup redesigned. Same Omarchy
Quattro plugin `agent-bar.usage` with the private Rust helper at
`bin/agent-bar`; no breaking changes.

## Highlights

- Claude collection works again: `Bearer` auth header, the
  `seven_day_oauth_apps` weekly bucket, window-id dedupe, and epoch
  `resets_at` support.
- Expired Claude sessions are retryable and keep the last good windows as
  stale instead of wiping them.
- Duration-based window labels everywhere: `5h Reset`, `7d Reset`,
  `1d Reset`, `{n}m Reset`.
- Layered popup: large primary windows with theme-accent tracks, per-model
  quiet list, stale banner with retry gated by `error.retryable`, and a meta
  footer. Reset and update times are humanized (`2h 30m · 14:59`, `5m ago`).
- Claude plan badge shows the real rate-limit tier (for example `Max 20x`).
- Claude and Grok HTTP collection share one transient-retry helper.
- `ServiceCore.js` split into five concern modules, with the QML enum
  mirrors locked to the Rust schema by a contract test.
- Dormant `anyhow` dependency and the unused forced-targets cache subsystem
  removed; the dependency scan now verifies real usage.

## Migration

None required. Settings, cache, and plugin layout are unchanged. Update an
existing install with the plugin's update flow or `omarchy plugin rescan`
after replacing the bundle.
