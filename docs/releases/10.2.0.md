# Agent Bar 10.2.0

Settings and the built-in updater actually work now, plus friendlier window
labels and popup polish. Same Omarchy Quattro plugin `agent-bar.usage` with
the private Rust helper at `bin/agent-bar`; no breaking changes.

## Highlights

- Settings save works: the settings write process closes stdin after
  writing, so the helper's `config apply stdin` receives EOF instead of
  hanging forever and never persisting anything.
- The updater works against real GitHub (#31): the release metadata download
  follows redirects under the closed host policy (≤5 HTTPS hops,
  `github.com`/`*.githubusercontent.com` only), like the archive and
  checksum downloads already did. This is the first release the update
  button can actually install.
- Window labels are named, not cryptic: `Session (5h)`, `Daily (1d)`,
  `Weekly (7d)`, and bare `{n}m` for other Codex durations.
- Chip tooltip reduced to `Name · percent`, appending the typed state only
  when it is not `ready`.
- The popup no longer opens with a few pixels of phantom scroll: the card
  height accounts for the panel border inset.

## Migration

None required. Settings, cache, and plugin layout are unchanged. Update an
existing install with the plugin's update flow or `omarchy plugin rescan`
after replacing the bundle.
