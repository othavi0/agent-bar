# Domain Documentation

This is a single-context repository.

Before changing behavior:

1. Read `CONTEXT.md`.
2. Read the accepted ADRs relevant to the change.
3. For v10 work, read `docs/specs/v10/README.md` and its canonical sequence.

`CONTEXT.md` defines current terminology. ADRs explain durable decisions.
`docs/specs/v10/` defines the approved transition contract and requirements.

Historical ADR bodies and `docs/superpowers/**` do not override the current
accepted v10 decision.
