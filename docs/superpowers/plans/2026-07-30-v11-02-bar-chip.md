# v11 Bar Chip — WidgetButton, Assets, Tooltip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the bar chip on Quattro's `WidgetButton` with host icon sizing, a fixed-width numeral, mark-grade monochrome assets tinted at render time, emoji-free state cues, and the humanized tooltip.

**Architecture:** `CoreView.js` gains the presentation decisions (optical scale, tint eligibility, state qualifier, numeral text) as pure functions locked by QML unit tests; `ProviderChip.qml` becomes a thin `WidgetButton` subclass that only lays out icon + numeral + cue; assets are corrected at the source (`codex.png` replaced by the approved mark derivation, `grok.svg` stripped of its hardcoded white fill) and tinted with `MultiEffect { colorization: 1.0 }`. The click protocol, tooltip delivery, dimmed semantics, and motion move wholesale to the host component.

**Tech Stack:** QML (Qt 6, Quickshell/Quattro host at `/usr/share/omarchy/shell`), `QtQuick.Effects.MultiEffect`, qmltestrunner (Qt 6 binary path only), Rust test gates untouched.

## Measured facts (2026-07-30, this machine)

Established during planning; tasks below rely on them.

1. **`MultiEffect { colorization: 1.0; colorizationColor: C }` multiplies source luminance by `C`, preserving alpha** (established during Task 2 execution with five independent GPU tests: black and near-black sources are unchanged, dark red goes gray, pure white becomes exactly `C`). Consequence: **white-on-transparency is the required mask convention** — a white mask (luma 1) renders exactly in `C` on both light and dark themes; a black mark can never take the theme ink. Original planning probe (white `codex-mark.png` over `#f2f2f0`, colorized to `#141317`, OpenGL RHI): plate mean fell 242 → **209.9**, predicted 209.8. This fact supersedes the earlier "replaces the color" wording; the visible outcome for white masks is identical.
2. **`QT_QPA_PLATFORM=offscreen` loads the *software* scenegraph backend, where `MultiEffect` renders nothing at all** (not even the source item; no warning is emitted). Consequence: qmltestrunner and any offscreen screenshot run are blind to the tint — tinted icons will be *absent* from offscreen captures. Tint verification is perceptual-on-GPU only (Task 4).
3. Host tokens (from `/usr/share/omarchy/shell/Commons/Style.qml`): `Style.bar.iconSlot` = 27, `Style.bar.iconCanvas` = 16, `Style.spacing.sm` = 4, `Style.spacing.md` = 6, `Style.spacing.xxl` = 12, `Style.font.body` ≈ 12 (scales with `[font] base-size`).
4. `WidgetButton` (`/usr/share/omarchy/shell/Ui/WidgetButton.qml`) already implements the whole UX-010 protocol: `registerClickTarget`/`unregisterClickTarget` sync, `function triggerPress(button)`, `signal pressed(int button)`, `tooltipText` delivery on hover, pointer cursor, `dimmed` → opacity 0.45 with host `Behavior on opacity`, readonly `vertical`/`barSize` derived from `bar`. Making `ProviderChip` *be* a `WidgetButton` yields exactly one registration — double-registration (the spec §5 concern) is structurally impossible. Its `MouseArea` consumes wheel events into an unconnected `wheelMoved` signal: wheel over a chip stays a user-visible no-op (UX-009).
5. OpenAI publishes no standalone monochrome Codex mark (checked 2026-07-30; only third-party logo repositories exist). Per visual design §10, the derivation `codex-mark.png` (64×64, white on transparency, 14.46% ink, derived from the official app icon) is adopted and recorded under UX-049.
6. The stale glyph is `󰅐` U+F0150 from the bar's Nerd Font family — the same glyph the approved mockup uses in the stale banner (`final.html:171`) and the same PUA-A plane as the `󰑐` U+F0450 already shipped in `ProviderHeader.qml:77`.

```js
// UX-012: text cue beyond color for stale/error. No leading space — the
// chip separates cue from numeral with layout spacing (visual design §5).
// 󰅐 is U+F0150 from the bar's Nerd Font family, replacing the emoji-font
// ⌛ that broke the monospace surface.
function chipStateCue(provider) {
  if (!provider)
    return ""
  var state = String(provider.state || "")
  if (state === "stale")
    return "󰅐"
  if (state === "cli_missing" || state === "unauthenticated" || state === "rate_limited"
      || state === "network_error" || state === "provider_error")
    return "!"
  return ""
}

// Copy design §5.4: lowercase trailing qualifier for the chip tooltip.
// Plan 03 deletes connectionLabel with the meta footer; this function is
// the humaniser that replaces it.
function stateQualifier(state) {
  var s = String(state || "")
  if (s === "ready")
    return ""
  if (s === "stale")
    return "stale"
  if (s === "loading")
    return "loading"
  if (s === "cli_missing")
    return "no CLI"
  if (s === "unauthenticated")
    return "signed out"
  if (s === "rate_limited")
    return "rate limited"
  if (s === "network_error")
    return "offline"
  if (s === "provider_error")
    return "failed"
  return "unknown"
}

// Numeral box content: loading renders the loading cue in place of the
// number so the cue is visually distinct from the — no-data glyph (§5).
function chipNumeralText(provider, metric) {
  if (provider && String(provider.state || "") === "loading")
    return "···"
  return chipPercentText(provider, metric)
}

// UX-011 (amended by this plan): provider, displayed percentage when one
// exists, and a plain-language qualifier when not ready. The raw enum
// value never renders (copy design §5.4).
function chipTooltip(provider, metric) {
  if (!provider)
    return ""
  var name = provider.name ? String(provider.name) : providerDisplayName(provider.id)
  var parts = [name]
  var state = provider.state ? String(provider.state) : "unknown"
  var pct = chipPercentText(provider, metric)
  if (pct !== "—" || state === "ready")
    parts.push(pct)
  var qualifier = stateQualifier(state)
  if (qualifier.length)
    parts.push(qualifier)
  return parts.join(" · ")
}

// Visual design §5/§10: per-provider optical scale on the shared 16px
// canvas. Grok's mark is a thin ring that fills its own box edge to edge.
function iconOpticalScale(id) {
  if (String(id || "") === "grok")
    return 0.875
  return 1.0
}

// §10: monochrome brands inherit the theme ink at render time; polychrome
// brands keep their official color and are never tinted.
function iconTinted(id) {
  var key = String(id || "")
  return key === "codex" || key === "grok"
}
```
